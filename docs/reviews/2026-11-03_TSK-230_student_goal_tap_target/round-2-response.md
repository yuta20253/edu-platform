# 第2周の批判への対応

判定: 直せば進めてよい

| 指摘 | 重大度 | 対応 | 理由・草案のどこを直したか |
|---|---|---|---|
| 1. `borderRadius: "inherit"` は 0 になる／`radius.md` の数値は 56px になる | 重要 | 採用 | `borderRadius: cardSx.borderRadius`（`studentTheme.ts` の export を参照）に変えた。「inherit が効かなければ」の分岐を消した |
| 2. 文字のずれ 4px 以内は IconButton の 44px 化と両立しない | 重要 | 採用 | 4-d の対象を「見出し行と『目標一覧』リンク」に絞った。右の列が広がる影響（一覧 +28px、ホーム +14px、折り返し・省略が増える）を利用者への影響に書いた。確認項目に「30 文字のタイトルで前後比較」を足した。ボタンに負のマージンを付ける案を、比較した案に理由つきで載せた（問い 5） |
| 3. 「目標一覧」リンクのはみ出しの余裕が 1px | 軽微 | 採用 | 設計 2 に「見出し行の `mb` は 12px 以上を保つ」と書き、実装時にコメントを残すとした |
| 4. BackLink の別チケットが起票されていない | 軽微 | 採用 | 対象外の欄に「このチケットと同時に Backlog に起票する」と書いた（問い 3。ID は起票後に書く） |
| 5. `stretchedLinkSx` の置き場所 | 軽微 | 採用 | `app/theme/studentTheme.ts` の `cardSx` の隣に置くと決めた。Home・Goals の自前の `cardSx` を共通のものに置き換えるのはこのチケットに混ぜない、と書いた |

## オーナーに確認する問い（手順 5 で聞く）

1. 押せる範囲は 44px でよいか → 草案は 44px
2. テキストリンクは負のマージンで「見た目を変えない」でよいか → 草案は「変えない」
3. 戻るリンクは `BackLink` の別チケットにして、今起票するか → 草案は「別チケット・同時に起票」
4. ボタンのすぐ外を押すと詳細に移る挙動を許容するか → 草案は「許容」
5. IconButton を 44px にして、目標一覧の進捗%が約 28px 左に動き、タイトルの折り返しが増えるのを許容するか → 草案は「許容」
