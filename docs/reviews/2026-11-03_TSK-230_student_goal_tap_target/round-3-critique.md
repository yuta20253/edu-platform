## 確かめた事実
- `studentTheme.ts` は `"use client"` のファイルで、`cardSx`（`as const`、`borderRadius: "14px"`）と `radius` を export している。Home・Goals はもともと `radius` をここから import していて、どちらも `"use client"` なので、`stretchedLinkSx` をここに置いても import の制約は増えない
- `cardSx.borderRadius` は文字列なので、`sx` の中で `theme.shape.borderRadius` は掛からない。草案のコメントどおり
- `globals.css` の `a { color: inherit }` により、ホームのタイトルの色は親から引き継がれる。`outline: "2px solid"` の色は currentColor（タイトルの色）になり、白いカードの上で見える
- `outlineOffset: 2` の枠はカードの外に 2px 出るが、カード同士の間隔は `mb: 1.25`（10px）なので、隣のカードには届かない
- `stretchedLinkSx` のキー（`&::after` / `&:focus-visible` / `&:focus-visible::after`）は、既存のタイトルの sx（`display` / `fontSize` など）と衝突しない。展開して合わせても値が上書きされない
