## 本人に確認すべき問い(手順5で聞く)

1. 走査テストをやめて、ESLint 1 本にしてよいか(10/23 は「走査テスト + ESLint」と決めていた)。
2. ルールの範囲: `CircularProgress` の import は `index.tsx` だけ、JSX の文言は `features/**/*.tsx` 全体、`loading` の分岐は `index.tsx` だけ、でよいか。
3. `teacher/CreateStudent` と `teacher/StudentDetail` のタブ切替後の失敗表示を、このチケットでは直さず、1 本のフォローアップチケット(Medium)で `ErrorState` に直すことにしてよいか。それまでは「一時」の例外として残る(違反が 2 画面残ったまま「禁止ルール導入済み」になる)。
4. `.ts` のフックに残る失敗文言(4 本)は、このチケットの対象外(レビューで確認)でよいか。
5. ESLint の設定のテストは、実行時間が 2 秒以内なら必須、超えたら PR 本文に貼る方式でよいか。
