# 第2周への対応

| 指摘 | 重大度 | 対応 | 理由・草案のどこを直したか |
| --- | --- | --- | --- |
| 1 優先度の型（string / number） | 重要 | 採用 | Rails の enum は文字列で返る見込みで、`typeof === "number"` の分岐により戻っても「普通」に戻る既存の不具合の可能性が高い。検証済みの前提に追加。このチケットでは直さず別件とし、回帰防止のテストは優先度を比べない（不具合を固定しない） |
| 2 Props `draftTaskId: number \| null` | 重要 | 採用 | 設計に Props を明記。page.tsx は `null` を渡し、`0`・不正値は `notFound()`。既存7件を `{null}` に直すことをやることに追記 |
| 3 単元の検証対象 | 重要 | 採用 | チェック済み表示と POST ボディの `unit_ids` で確かめると明記。フォーム値の `unit_ids` は見ない |
| 4 単元の二重管理 | 軽微 | 採用 | 範囲外と明記。完了条件を言い換えた |
| 5 共通フックの変更 | 軽微 | 採用 | `useUnitSelection` の単体テスト1件と PR 説明への記載を追加 |
