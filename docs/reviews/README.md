# 設計レビューの記録

チケットや設計の草案を、批判役（`.claude/agents/design-critic.md`）にレビューさせた記録を残す場所。
流れは `/draft-ticket`（`.claude/skills/draft-ticket/SKILL.md`）を参照。

## フォルダの構成

```
docs/reviews/<YYYY-MM-DD>_<チケットID>_<slug>/
  draft.md               # 最終的な草案（Notion チケットの本文と同じ内容）
  round-1-critique.md    # 第1周の批判（批判役の出力をそのまま保存）
  round-1-response.md    # 第1周の対応表（指摘ごとに採用／不採用と理由）
  round-2-critique.md
  round-2-response.md
  ...
```
