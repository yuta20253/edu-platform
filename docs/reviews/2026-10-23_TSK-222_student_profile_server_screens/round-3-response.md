# 第3周の対応(UserProfile / EditUserProfile)

第3周の判定: **このまま進めてよい**

| 指摘 | 重大度 | 対応 | 理由・草案のどこを直したか |
| --- | --- | --- | --- |
| 1. 実画面確認が「やること」に無い(未検証表と完了条件にだけある) | 軽微 | 採用 | 「やること」に、実画面確認の項目を1行足した(了承がなければ PR 説明に「未検証」と書く) |
| 2. 確認手順に、修正前の再現と、期待結果の before / after が無い | 軽微 | 採用 | 「修正前に現行のブランチで再現を取り(`/profile` はスピナーで止まる、`/profile/edit` は既定のエラー画面)、修正後に `/login` に遷移することを確かめる。修正前に再現できなければ、推測が外れたと分かる」を、上の項目に書いた |
